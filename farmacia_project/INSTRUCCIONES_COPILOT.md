# Instrucciones Copilot

Este proyecto fue creado de forma independiente en la carpeta `farmacia_project` sin tocar el proyecto original ubicado en `django_project/src`.

## Objetivo
Crear una aplicación Django llamada `FarmaPoint` para evaluar la viabilidad de ubicaciones para nuevas boticas.

## Puntos clave
- Proyecto base: `farmacia_project/src`
- App: `farmacia`
- Configuración: `config`
- Sin base de datos
- Sin ORM
- Sin migraciones
- Datos en memoria
- Formularios con `forms.Form`
- Templates con herencia desde `base.html`
