## Capturas reales que todavía hacen falta

Las evidencias de DevTools/Network, navegador, consola y terminal no se pueden sustituir por mockups. Para completar el Word, toma esas capturas ejecutando el proyecto: Network debe enseñar la URL/método/estado/respuesta reales; terminal debe enseñar lint, build y git status. El entorno usado para preparar la carpeta no pudo descargar dependencias de npm ni PyPI, por lo que no hay resultados reales de esas pruebas.

En LAB12, arranca Django desde `farmacia_project/src` y React desde `frontend`, cada uno en su terminal. Instala primero `python -m pip install -r requirements.txt` y `npm install`.
